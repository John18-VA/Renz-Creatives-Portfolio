# Netflix-Style VA Portfolio

A red-and-black, Netflix-inspired portfolio website for a Virtual Assistant.

## Run it in VS Code
1. Open VS Code, then File > Open Folder, and choose this folder.
2. Accept the prompt to install the recommended extensions (Live Server).
3. Right-click index.html and choose Open with Live Server.

## Folder structure
    va-portfolio-site/
    |-- index.html        all page text and links
    |-- css/
    |   |-- style.css     colors, fonts, layout (change --red at the top)
    |-- js/
    |   |-- script.js     profile screen, row arrows, nav highlight, plan picker
    |-- assets/
    |   |-- images/       put your photo, logo and screenshots here
    |-- .vscode/          editor settings and recommended extensions
    |-- README.md

## What to edit first
- Replace every [bracketed] placeholder in index.html.
- Update the contact links at the bottom of index.html: your@email.com, the WhatsApp number, LinkedIn and Calendly URLs.
- Add images to assets/images/ and use them like: <img src="assets/images/me.jpg" alt="Your name">

## Put it online
Drag the whole folder into Netlify Drop, or push it to GitHub and enable GitHub Pages.
